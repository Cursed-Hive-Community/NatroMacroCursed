# A fuzzy that connects after the main has already said where it is.
#
# This is a macro that restarted. It used to be told nothing until the main
# changed field, which on a one-field setup is never.

# the seats go in before the coordinator reads the roster,
# rather than relying on it to notice a reload
seat 1 main bench main
seat 2 fuzzy bench fuzzy
coordinator start
wait 2500
connect 1
wait 1500
field 1 mountain top
wait 1500

say --- now the resident arrives, long after ---
clear all
connect 2
wait 2000
expect 2 GOTO field=mountain top
